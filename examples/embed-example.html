This is a minimal skeleton that shows where the wz-editor marker block goes and which elements become editable. Swap this content for a real document — nothing about the editor cares what's above the marker block.

Any element matched by wz-editor's default selector (headings, paragraphs, list items, table cells, and a handful of report-style content classes — see DEFAULT_EDIT_SEL in wz-editor.js) becomes contenteditable once you unlock edit mode. Set editableSelector in the config below to override that heuristic for your own document's class names.

  • Click the pencil icon in the top-right corner.
  • Enter the demo password: demo (this page's pwHashHex below is the SHA-256 hash of that word — replace it with your own before using this for real; see the README's Quick Start for how to compute it).
  • Edit any paragraph, heading, or list item on this page.
  • Press Save. With no GitLab token configured (as below), this will show a failure toast — that's expected. Nothing is lost; the edit stays on the page and in the localStorage draft.
